# API documentation

Only `GET /health` is currently implemented in the Fastify server.

The [backend and API plan](backend-plan.md) describes proposed production boundaries, permissions, data models, routes and delivery phases. Every application endpoint listed there is planned, not available today.

The [Claude backend brief](../handoff/claude-backend-brief.md) provides implementation instructions. Current frontend types are in `apps/web/app/lib/content.ts`, `page-content.ts` and `activities.ts`.
